# Офлайн-проверки

Запуск из корня проекта в Linux/WSL: `make check` (или `make test`).

- `cases.hpp` — 95 проверок функций и моделей: конфигурация, кодирование и HMAC, разбор JSON/protobuf, книга, лимиты, paper и live-учёт, задержки, replay. Включены 50 фиксированных сценариев учёта по 100 сделок.
- `test_main.cpp` — один набор тестов для новой и исходной реализаций.
- `reference/spred_legacy.cpp.gz` — точная сжатая копия исходного монолита, только эталон регрессии. Никогда не участвует в сборке рабочего `spred`. SHA256 распакованного файла: `2d47816c077920f7265643429a73b739b1f34d5c7da0e7b2748bcaad30eaf632`.
- `run_checks.py` — сравнение снимков результатов, три synthetic raw-replay по 1000 кадров, проверки защит CLI, независимой компиляции заголовков и синтаксиса утилит.
- `offline_guard.c` — тестовая Linux-библиотека: `connect` всегда возвращает отказ, `getaddrinfo` не разрешает имена. Через `LD_PRELOAD` применяется только к запущенным из тестового стенда процессам.

В replay ответ `exchangeInfo` заменяется локальным mock-curl с единственным разрешённым URL-запросом к фиктивному адресу. Никакие настоящие учётные данные не используются. Для сравнений из окружения удаляются все унаследованные `MM_*`. Настоящий curl и сетевые запросы не нужны.

Сравнение replay нормализует только метки настенных часов `HH:MM:SS[.mmm]`. P&L, счётчики, события исполнения и сводки сравниваются без удаления. Тестовые raw-записи, бинарники и снимки сохраняются в `build/`, удаляются командой `make clean` и не предназначены для коммита.

Границы проверки: синтетические сценарии не покрывают весь рынок, все отказы сети, поведение биржи и многопоточность. Защиты live проверяются до открытия сети, без live-подтверждения. Это не интеграционный аудит реальной торговли.
